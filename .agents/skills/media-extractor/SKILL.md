# Extracción de Contenido Multimedia

- Utiliza la navegación web integrada para buscar perfiles públicos de la marca en Instagram o Facebook.
- Localiza URLs públicas válidas de imágenes indexadas para rellenar los componentes visuales en las etiquetas <img>.
- En caso de restricciones de acceso o privacidad en las redes, utiliza imágenes de stock libres con dimensiones explícitas acorde a la temática del proyecto.
